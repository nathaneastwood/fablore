# Seers Language

<div data-glyph-alphabet="seers"></div>

Only 17 of the 26 letters have ever been published. **B**, **C**, **J**, **K**,
**Q**, **V**, **W**, **X** and **Z** have never appeared in card art, and render
as empty runes above — so most English sentences cannot be written in full.
Every attested glyph has been traced into a typeface; type into the box below
and see how far the Seers' script will carry your own words.

<div data-glyph-tool="seers"></div>

No Seers text has ever shown a punctuation mark or a numeral either, so the
typeface will write letters and spaces alone.

The only known reference to this language was in the story [A Grand Adventure](../main-story/everfest/a-grand-adventure.md).

> This age of Gods and Monsters. Ophidia the _ eeder of the Fyendal will one day return
